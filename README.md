# Revcenter docs

The source of [docs.revcenter.ai](https://docs.revcenter.ai): guides, recipes and the API reference for
the Revcenter API, the `revcenter` CLI and the Revcenter MCP server.

- Start here: [Quickstart](https://docs.revcenter.ai/quickstart)
- For agents: [llms.txt](https://docs.revcenter.ai/llms.txt)
- Use Revcenter from your coding agent: [revcenter/agent-plugins](https://github.com/revcenter/agent-plugins)

This repository is published from Revcenter's main repository; changes made here directly are
overwritten by the next publish. To report a problem with the docs, open an issue.
