> Agents: the full documentation index is at [/llms.txt](https://docs.revcenter.ai/llms.txt).

**Base URL:** `https://api.revcenter.ai/v1`. Send `Authorization: Bearer <your key>` ([Authentication](/authentication)).
Bodies are JSON. Results are wrapped in `data`, lists add a `cursor`, and every response has a `request_id`:

```json
{ "data": { "id": "6a1e…", "name": "Controller, Camden NJ" }, "meta": { "request_id": "6f1c2b7e-…" } }
```

Each endpoint's page states its cost: free, re-scoring (free), charged on a search's own reservation, or a launch
or expansion reserving up to `max_credits` (unused credits are refunded). Waiting, paging, limits and retries are
in [API essentials](/guides/api-essentials). `GET /health`, `POST /auth/device` and `POST /auth/token` need no key.

## Errors

Every error has one shape, and its `request_id` is what support needs:

```json
{ "error": { "code": "search_not_found", "message": "No search with that id in this workspace.", "details": null, "request_id": "6f1c2b7e-…" } }
```

The MCP servers return the code, the fix below and the `request_id` as an error result, with `retryable` saying
whether the same call may simply be repeated. Retry `429` after
`Retry-After` and `5xx` with backoff ([which calls are safe](/guides/api-essentials#retries-and-idempotency)); fix
any other `4xx` first.
